# 최근 20건 분석 현황을 라이브 보기로 이동

홈의 최근 분석 흐름 카드(상태별 횟수 그래프·최근 분석 기록)를 제거하고 라이브 영상 아래에 실시간 분석 현황으로 배치했다. 현재 계정의 최근 최대 20건을 사용한다. 특정 카메라만의 결과라고 표시하지 않는다.

상태별 분석 횟수, 결과별 분류/점수/시각, 기본 4건과 전체 20건 펼쳐보기, 수동 새로고침을 유지한다. 화면이 보이는 동안 5초마다 갱신하고 알림/화면 복귀에도 갱신한다. 조회 오류는 이전 결과와 재시도를 표시하고, 계정 전환/화면 종료 시 오래된 응답과 타이머를 정리한다. 라이브 카메라 목록 오류 시에도 분석 현황을 따로 조회한다.

기존 /api/emotions/history와 계정별 조회 hook을 재사용한다. hook의 기본 15초 주기는 다른 카드에서 유지하고 이 패널만 5초를 지정한다. 홈은 별도 분석 현황 조회를 하지 않는다(구형 서버용 대표 상태 호환 계산은 별도). 분석/학습/DB/원본 데이터는 변경하지 않았다.

변경 파일: HomePage.jsx에서 패널과 전용 조회 제거, components/live/LiveAnalysisHistory.jsx 추가, LivePage.jsx에서 영상 아래 연결, useAccountStatus.js에 조회 주기 옵션 추가, 관련 테스트. Android v1.21/versionCode22.

검증: 프런트엔드 33개 파일/154개 테스트 통과. 홈에서 패널 없음, 라이브에서 20건 제한·펼침·오류·재조회, 계정별 상태와 펼침 초기화, 5초 주기·알림 갱신을 검증했다. 실제 Edge 390×844와 임시 SQLite에서 합성 분석 21개 입력 후 홈 현황 조회 0회, 라이브 20건 표시·펼침을 확인했다. 새 분석 추가 후 수동 조작 없이 새 점수가 표시됐으며 가로 넘침이 없었다.

Vite android build/cap sync/Gradle assembleDebug 성공. 실기기 설치·실제 카메라 스트리밍은 이번 시험에서 실행하지 않았다. 운영 데이터/FCM에는 접근하지 않았다. 이번 변경은 추가 DB 작업과 API/Worker 재배포가 필요 없으며 Vercel main 배포와 새 APK 설치 또는 Android Studio build/sync로 적용한다.
