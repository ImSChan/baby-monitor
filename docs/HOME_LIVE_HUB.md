# 홈 라이브 카드 및 하단 탭 제거

홈의 개인화 학습 상태 카드 자리를 홈캠 라이브 카드로 대체하고 아래쪽 중복 라이브 영역을 제거했다. 설정 화면의 개인화 학습 카드도 제거했다. 학습 API/피드백 파이프라인/DB/가중치는 변경하지 않았다.

- 홈은 분석 결과 → 홈캠 라이브 순서로 표시한다. 최근 분석 흐름은 라이브 보기 화면으로 이동했다(LIVE_ANALYSIS_HISTORY.md).
- 연결 확인 중, 홈캠 없음, 온라인 홈캠 목록, 연결 확인 필요를 구분한다. 조회 실패 시 이전 목록을 온라인 상태로 표시하지 않는다. 서버에 홈캠이 등록돼 있다는 것과 실제 영상 프레임 수신은 구분하며 영상 수신/멈춤은 기존 라이브 화면에서 확인한다.
- 같은 계정의 홈캠 이름과 바로 보기, 라이브 보기, 홈캠 시작, 연결 새로고침과 마지막 확인 시간을 제공한다. 홈캠이 없거나 조회 오류여도 라이브/홈캠 시작 진입은 유지한다.
- 이름을 선택하면 /live?session=<id>로 이동한다. 상세 화면은 인증된 서버 세션 목록에서 일치하는 항목만 찾아 연결하며 외부/존재하지 않는 ID를 URL만 보고 연결하지 않는다. 같은 선택을 갱신 때마다 중복 연결하지 않는다. 실제 WebRTC/영상 멈춤 확인/다시 연결/종료 기능은 기존 상세 화면을 사용한다.
- 하단 라이브 탭을 제거하면서 하나만 남는 홈 탭도 함께 제거했다. 상세 화면 상단에 홈으로 링크를 제공해 라이브/홈캠/설정/알림/돌아보기에서 홈으로 복귀한다. 남은 바닥 탭 공간도 정리했다.

주요 변경: HomePage.jsx, HomeLiveCard.jsx(추가), LivePage.jsx(선택 홈캠 진입), SettingsPage.jsx, App.jsx, HomeReturnLink.jsx(추가), BottomNav.jsx 삭제 및 관련 테스트. Android v1.15/versionCode16.

검증: 프런트엔드 27개 파일/120개 테스트 통과. 홈 카드 순서·단일 표시·학습 카드 제거, 세션 없음/로딩/오류/복수 홈캠·URL 인코딩, 현재 계정 목록에 있는 선택 세션만 1회 연결, 홈 복귀 동선을 확인했다. Vite android build/Capacitor sync/Gradle assembleDebug 성공.

실제 Edge 390×844에서 로컬 임시 SQLite의 계정으로 홈캠 없음 → 라이브 화면 → 홈 → 홈캠 시작 화면 → 홈을 확인했다. 온라인/장애 시나리오는 합성 세션 목록 응답과 503을 모의해 화면·기존 목록 숨김·바로 보기 경로를 확인했다. 하단 nav 0개, 개인화 학습 카드 0개, 라이브 카드 1개, 가로 넘침 없음. 이번 시험에서 실제 카메라 촬영·원격 영상 전송·실기기 설치·운영 API·실제 FCM은 실행하지 않았다.

적용: GitHub main 연동 Vercel 배포를 확인하고 내장 자산 Android는 v1.15 APK로 갱신하거나 npm.cmd run build -- --mode android / npx.cmd cap sync android 후 Android Studio에서 재빌드한다. 이번 변경의 추가 DB 작업과 백엔드 재배포는 없다. 운영 자동 재배포는 수행하지 않았다.
